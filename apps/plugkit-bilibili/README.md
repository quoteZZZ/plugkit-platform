# PlugKit Bilibili（B站管理）

B 站统一管理插件：拦截 PCDN 与上传占用、净化页面、增强播放、管理弹幕。

## 功能

| 模块 | 能力 |
|------|------|
| 资源拦截 | PCDN 域名拦截（基础档默认开，激进档可选）、直播 WebRTC 上传阻止、遥测上报拦截 |
| 统计 | 今日/累计：拦截请求数、阻止上传字节与次数、清理广告数——**全部为实测值，不含估算** |
| 页面净化 | 清理首页/直播间/动态的广告与推广元素 |
| 播放 | 固定倍速 0.1–16×、自动宽屏、记忆播放进度、精确统计数字 |
| 弹幕 | `Alt+D` 一键开关、透明度调节 |
| 夜间模式 | 整站暗色，`Alt+N` 切换 |
| 下载 / 导出 | 视频（交给浏览器下载管理器）、封面、弹幕 XML（后两者默认关闭） |
| 账号 | 每日自动签到 |

## 设计取舍：为什么砍掉一些功能

已移除：画质档位选择、倍速「记住上次」模式、UP 主属地、复制封面 / 复制标题链接、
字幕下载、自动播放、右下角清晰度徽标、流量估算。

理由：它们与「防止平台偷占带宽」无关，或与 B 站自带能力重复，或价值过低。
保留它们只会挤占播放页空间、扩大维护面。默认关闭封面下载与弹幕导出同理——按需在设置里打开。

## 安装（本地加载）

1. 构建：`cd apps/plugkit-bilibili && pnpm exec wxt build`
   > 注意：不要用 `pnpm run build`。本机 pnpm 经 cmd.exe 调用 wxt 的 .CMD shim 会静默失败。
2. `chrome://extensions` → 打开开发者模式 → 加载已解压的扩展程序 → 选 `apps/plugkit-bilibili/.output/chrome-mv3`
3. 打开任意 B 站页面；已打开的标签页需刷新（content script 只在页面加载时注入）

## 快速上手

- 点工具栏图标：看今日实测数据、总开关、五个功能胶囊
- 设置页（图标右键 → 选项）：分组调参（拦截、页面、播放、弹幕、下载、账号、统计）
- 视频页：信息区出现「下载视频」按钮，`Alt+D` 开关弹幕

## 注意事项

- 激进档连正常 CDN 一起拦，可能影响加载，如遇异常请关闭
- 自动签到需浏览器在运行且已登录 B 站；遇风控请关闭
- PCDN / 遥测拦截由浏览器内核 DNR 完成，零 JS 开销；content 脚本保持 5–9KB 轻量
- 结构约定：`window.__INITIAL_STATE__` 只能在 MAIN world 读取。
  content script 处于 isolated world，必须经 `entrypoints/page-bridge.content.ts` 转发，
  详见 `src/shared/meta.ts` 顶部注释。
