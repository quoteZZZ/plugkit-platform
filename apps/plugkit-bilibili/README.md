# PlugKit Bilibili（B站管理）

B 站统一管理插件：拦截 PCDN/直播上传占用、广告净化、播放增强、弹幕管理、账号工具与流量统计。

## 功能一览

| 模块 | 能力 |
|------|------|
| 资源拦截 | PCDN 域名拦截（基础档默认开，激进档可选）、直播 WebRTC(P2P) 上传阻止 |
| 流量统计 | 今日/累计：PCDN 拦截次数、阻止上传字节、清理广告数、估算省流量 |
| 页面净化 | 自动清理首页/直播间/动态的广告与推广元素 |
| 播放增强 | 自定义倍速 0.1–16×、自动宽屏、记忆播放进度、自动播放 |
| 弹幕管理 | `Alt+D` 一键开关弹幕、透明度调节 |
| 账号工具 | 每日自动签到（保守版，不投币）、一键签到、复制封面、UP 属地显示、BV/AV 互转 |

## 安装（本地加载）

1. 构建：`pnpm -F @plugkit/plugin-bilibili build`
2. `chrome://extensions` → 开发者模式 → 加载已解压 → 选 `apps/plugkit-bilibili/.output/chrome-mv3`
3. 打开任意 B 站视频页，功能自动生效

## 快速上手

- 点工具栏图标：看今日统计、四功能快捷开关、「立即签到」
- 设置页（图标右键 → 选项）：分组调参（倍速、透明度、自动签到、激进档等）
- 视频页：UP 名字旁显示属地、「复制封面」按钮、`Alt+D` 开关弹幕

## 注意事项

- 激进档可能影响视频加载，如遇异常请关闭
- 自动签到需浏览器在运行且已登录 B 站；如遇风控请关闭该功能
- 视频下载、弹幕屏蔽词/字号规划中（涉及接口级过滤）
- PCDN 拦截由浏览器内核(DNR)完成，零 JS 开销；content 脚本保持 5–9KB 轻量
